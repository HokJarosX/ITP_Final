A personal finance tracker designed to help users manage, track, and analyze their financial transactions.
The application allows users to organize expenses, monitor spending habits, and view financial summaries in a simple and convenient way.

Features

The program includes the following functions:

Set a budget – define a spending limit for better financial planning
Show all transactions – display the complete list of financial operations
Show categories – view available transaction categories
Show monthly summary – analyze income and expenses for a selected month
Show overspendings – identify cases where spending exceeded the budget
Filter by category – display transactions from a specific category
Filter by date – search transactions by a chosen date or period
Exit – close the application
